# P8. The positivity sieve as a theorem

Prove, with explicit delays, that window positivity with the true past fixed forces the next prime-power weight to Lambda(n)/sqrt(n)
(excess side: Maximality, proved; deficit side: coarse lemma proved modulo admissibility) and forces zero weight at composites. The
sharp delay law delta = z^2/(2 c^2) (boundary-layer law, results/04) is checked to machine precision but conditional as stated.
A rigorous version is RH-neutral and would make "positivity determines the primes" a theorem.
